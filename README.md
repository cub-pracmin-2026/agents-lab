# Review Tool and Explainer Skill

- `.agents/skills/review/` — task 1: the review skill, with `SKILL.md` and the code of the server.
- `programs/` — task 2: the training and validation programs that the explainers explain.
- `explainers/` — task 2: every explainer of the experiment, one self-contained HTML file each, with its
  comments file.
- `skill/explain/` — task 2: the explainer skill made from my review comments.
- `report.md` or `report.html` — task 2: the agent and the model, the design of the experiment, the results
  and how much the skill helps.
